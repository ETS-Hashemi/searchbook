# Chapter 9 — Conflict-Based Search (priority Essential; Week 4)
File Overleaf/chapters/ch09-cbs.tex, label ch:ch09. Algorithm template. Target 16-18 pages. THE central MAPF chapter.
Anchors: Sharon, Stern, Felner & Sturtevant, "Conflict-Based Search for Optimal Multi-Agent Pathfinding", AIJ 219 (2015) 40-66 (and the AAAI 2012 version); Boyarski et al., ICBS, IJCAI 2015; Felner et al., ICAPS 2018 (CBSH heuristics); Li et al., AAAI 2019 (symmetry breaking).
Week 4 of the plan: "Constraint tree, high-level search, low-level A*, branching on conflicts. Implement basic CBS from scratch for a grid. Test 2, 4, and 8 agents. Milestone: a working optimal CBS solver on small instances."
Must cover: the two-level idea (high level searches a binary Constraint Tree over sets of constraints; low level plans one agent under its constraints with space-time A* from ch:ch04); definitions: constraint (a_i, v, t) and (a_i, u, v, t), CT node = (constraints, solution, cost), the root has no constraints; the high-level loop: pop the CT node of lowest cost (best-first on sum of costs), validate its solution, if conflict-free return it, otherwise pick the first conflict (a_i, a_j, v, t) and generate TWO children, each adding one constraint forbidding one of the two agents from that vertex/edge at that time, and replan only that agent's path; pseudocode for both levels; a FULLY worked example: a small grid with 2-3 agents whose shortest paths conflict, with the constraint tree drawn as a figure (root, two children, constraints and costs annotated) and a table listing each CT node with its constraints, per-agent path costs and total cost; theorems: CBS is complete and returns a sum-of-costs optimal solution, with proofs (key lemma: for any conflict between a_i and a_j at (v,t), every valid solution satisfies at least one of the two child constraints, so the split loses no solution; the high level is a best-first search on a tree whose leaf costs lower-bound their subtrees); complexity discussion (exponential in the number of conflicts, not in the number of agents directly; why CBS beats A* on the joint state space for loosely coupled instances, with the "corridor" vs "open room" contrast); implementation notes (which conflict to split on, the low-level must respect constraints AND the "goal occupied later" test, duplicate-node avoidance, memory, tie-breaking on fewer conflicts); improvements section: cardinal/semi-cardinal/non-cardinal conflicts and prioritizing cardinal ones, the bypass technique, meta-agent CBS in one paragraph, CBSH admissible heuristics for the high level, rectangle/corridor symmetry breaking (concepts + one figure); a generated experiment: success rate and CT nodes expanded vs number of agents (2,4,6,8) on random grids, with a runtime cap (pgfplots from .dat); pitfalls (splitting on a conflict but forgetting to replan only the constrained agent, constraints must accumulate down the tree, an agent sitting at its goal still conflicts, unbounded time horizon); drone box (CBS/ECBS as the global swarm planner: nominal time-indexed routes before flight, and the re-check after any replan in ch:ch24); 8-10 exercises incl. the Week-4 coding exercise (implement CBS from scratch, test 2/4/8 agents), a hand-built constraint tree, and a proof exercise.
