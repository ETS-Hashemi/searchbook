# Chapter 14 — The Dynamic Window Approach (priority High; Week 7)
File Overleaf/chapters/ch14-dwa.tex, label ch:ch14. Algorithm template. Target 12-14 pages.
Anchor: Fox, Burgard & Thrun, "The Dynamic Window Approach to Collision Avoidance", IEEE Robotics & Automation Magazine 4(1) 1997, 23-33.
Week 7: "Short-horizon control, local minima, oscillation, robot dynamics."
Must cover: the difference from VO/ORCA - DWA searches the space of ACHIEVABLE velocity commands over one control interval and scores short simulated rollouts, so it respects the robot's dynamics; the velocity space (v, omega) for a differential-drive robot and (vx, vy, vz) for a velocity-controlled drone (present both, use the drone form in the drone box); the three restrictions that define the search set, each with a figure: (1) the space of possible velocities, (2) ADMISSIBLE velocities - those from which the robot can still stop before hitting the nearest obstacle: v <= sqrt(2 * dist(v,omega) * a_break), with the derivation; (3) the DYNAMIC WINDOW - velocities reachable within the next time step given acceleration limits: [v - a*dt, v + a*dt] x [omega - alpha*dt, omega + alpha*dt]; the objective G(v,omega) = sigma(alpha*heading + beta*clearance + gamma*velocity) with each term defined precisely and the role of smoothing/normalisation; pseudocode; a worked example with numbers from the code: a drone approaching an obstacle, the dynamic window drawn in velocity space with the admissible region and the chosen command (figure), and a table of the three objective terms for several candidate velocities; the rollout/trajectory-prediction view (circular arcs for differential drive, straight segments for a velocity-controlled drone); properties: DWA is a LOCAL method - it is not complete, it can get stuck in local minima (a U-shaped obstacle; figure) and it can oscillate; the standard remedies (a global path providing the heading term, a longer horizon, hysteresis); tuning the weights with a figure/table showing what happens when each weight dominates; a generated experiment: trajectories through a corridor and into a U-trap for three weight settings (pgfplots from .dat); comparison table DWA vs ORCA vs APF (what each assumes, what each guarantees, cost per step); implementation notes (resolution of the velocity grid, cost of rollouts, obstacle distance queries, using the global path as the heading reference); pitfalls (forgetting the braking constraint, scoring in different units without normalisation, a dynamic window so small that the robot cannot react, treating moving obstacles as static during the rollout); drone box (DWA as the alternative local layer when the drone's acceleration limits matter more than reciprocity; how the nominal path supplies the heading term); 8 exercises incl. the Week-7 coding exercise (implement DWA in a continuous environment and create failure cases).
