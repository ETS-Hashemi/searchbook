# Chapter 13 — Reciprocal Avoidance: RVO and ORCA (ORCA Essential, RVO High; Week 6)
File Overleaf/chapters/ch13-rvo-orca.tex, label ch:ch13. Algorithm template. Target 15-17 pages. One of the most important chapters.
Anchors: van den Berg, Lin & Manocha, RVO, ICRA 2008; van den Berg, Guy, Lin & Manocha, "Reciprocal n-Body Collision Avoidance" (ORCA), ISRR 2011, Springer STAR 70, 3-19; Snape et al., HRVO, T-RO 2011; Alonso-Mora et al., non-holonomic ORCA, DARS 2013.
Must cover: the reciprocal dance/oscillation problem from ch:ch12 restated precisely; RVO: instead of choosing outside VO, choose a velocity whose AVERAGE with the current velocity lies outside the VO, i.e. RVO_{A|B}(v_B, v_A) = {v : 2v - v_A in VO_{A|B}(v_B)} - the apex moves to (v_A+v_B)/2 (figure), each agent takes half the responsibility, and the oscillation disappears (figure comparing VO and RVO trajectories from the code); why RVO can still fail with more than two agents (no guarantee, and the "reciprocal dance" among three); ORCA: the derivation, step by step and with a figure at each step: (1) for agents A and B and horizon tau, form the truncated VO^tau_{A|B} in relative-velocity space; (2) take the current relative velocity v_rel = v_A - v_B; (3) find u = the smallest change that takes v_rel to the boundary of VO^tau (the vector from v_rel to the closest point on the boundary), and n = the outward normal there; (4) ORCA^tau_{A|B} = {v : (v - (v_A + u/2)) . n >= 0} - a HALF-PLANE in velocity space; each agent takes half of u, hence "optimal reciprocal"; state the exact case analysis for the closest point (on the two legs, on the truncating arc/disc); the per-agent optimisation: choose the velocity in the intersection of all half-planes (and the disc ||v|| <= v_max) that is closest to the preferred velocity v_pref - a small convex program solved by the incremental 2D linear-programming algorithm (randomised, expected linear time), with pseudocode and a figure of the half-plane intersection; INFEASIBILITY: in dense situations the intersection can be empty; the standard remedy (the 3D/dense LP that minimises the maximum penetration, i.e. relax the constraints uniformly) explained conceptually with pseudocode; non-cooperative obstacles: if B does not avoid (an intruder, a static obstacle), A takes FULL responsibility - u instead of u/2 - and the resulting half-plane (this is the case that matters for ch:ch24, so make it explicit); 3D ORCA (half-SPACES; same construction with cones in R^3); a fully worked numeric example from the code (two agents, the half-plane coefficients, the chosen velocity) with a table; a generated simulation figure: 8 agents on a circle swapping antipodal positions, no-avoidance vs VO vs ORCA, with trajectory traces and a plot of minimum separation over time (pgfplots); properties: ORCA guarantees collision-free motion for the horizon tau if the LP is feasible and all agents run ORCA with the same tau, and it is NOT a global planner (deadlocks in narrow passages, no completeness); implementation notes (RVO2 library, kd-tree neighbour queries, tau vs time step, v_pref from the global path, agent radius inflation for safety); pitfalls (mixing reciprocal and non-reciprocal responsibility, wrong normal orientation, tau too small/large, ignoring the max-speed disc, applying ORCA to an agent that must hold a formation); drone box (the local safety layer: v_pref comes from the nominal CBS path, the intruder is handled with full responsibility and an uncertainty-inflated radius from the prediction of ch:ch20); 8-10 exercises incl. the Week-6 coding exercise (compare no avoidance, VO and ORCA on crossing agents) and half-plane derivations.
