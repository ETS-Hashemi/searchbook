# Chapter 12 — Velocity Obstacles (priority Essential; Week 6)
File Overleaf/chapters/ch12-velocity-obstacles.tex, label ch:ch12. Algorithm template. Target 13-15 pages.
Anchor: Fiorini & Shiller, "Motion Planning in Dynamic Environments Using Velocity Obstacles", IJRR 17(7) 1998, 760-772.
Week 6: "Collision cones, relative velocity, reciprocal avoidance."
Must cover: the shift from planning in position space to CHOOSING A VELOCITY; two discs A (radius r_A, position p_A, velocity v_A) and B; relative position p_B - p_A and relative velocity v_A - v_B; the COLLISION CONE CC_{A|B} = set of relative velocities that lead to a collision = the set of v_rel whose ray from the origin intersects the disc of radius r_A + r_B centred at p_B - p_A (define via the Minkowski sum from ch:ch02 and the tangent lines from ch:ch02); the VELOCITY OBSTACLE VO_{A|B} = CC translated by v_B; the geometry derivation with a full figure (workspace on the left, velocity space on the right, cone apex, tangent lines, the disc); the exact tangent-angle formula: half-angle asin((r_A+r_B)/||p_B-p_A||) around the direction to the obstacle; TIME TO COLLISION for a chosen velocity (solve ||p_rel + t v_rel|| = r_A + r_B, the quadratic, with the discriminant condition) and the TRUNCATED VO for a time horizon tau (the cone cut by an arc/disc of radius (r_A+r_B)/tau; figure), which is what makes VO usable in practice; choosing a velocity: the feasible set = disc of reachable velocities minus the union of VOs, and a cost function (stay close to the preferred velocity toward the goal); a worked example with numbers from the code: two drones on a crossing course, the VO computed, the chosen avoiding velocity, and the resulting trajectories (figure with the trajectory traces); the OSCILLATION problem when both agents apply VO simultaneously and each reacts to the other's new velocity (figure showing the oscillating trajectory) - this motivates ch:ch13; multiple obstacles (union of VOs); static obstacles as a VO with v_B = 0; the 3D cone in one section (a right circular cone in R^3; the same tangent half-angle; drones fly in 3D); a generated experiment: minimum separation and path length with no avoidance vs VO for a set of crossing agents (pgfplots); implementation notes (numerical care when agents nearly touch, the horizon, sampling candidate velocities vs solving exactly); pitfalls (forgetting to add the radii, using absolute instead of relative velocity, no truncation so the agent refuses far-future collisions, discretisation of the velocity sample set); drone box (VO/ORCA as the local safety layer triggered by the safety horizon of ch:ch24; a non-cooperative intruder is exactly the VO case, not the reciprocal one); 8 exercises incl. the Week-6 coding exercise (2D simulation with agents crossing, compare no avoidance vs VO) and geometry proofs.
Code: Overleaf/code/ch12_velocity_obstacles.py: collision cone and VO construction (apex, tangent directions), time to collision, truncated VO membership test, velocity selection by sampling, a small simulator producing trajectories; self-test: analytic checks (a head-on velocity is inside the VO, a perpendicular one is not, time-to-collision matches a closed-form case), and a simulation in which VO keeps the minimum separation above the sum of radii.
