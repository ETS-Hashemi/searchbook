% Glossary terms from ch07: lines of the form \item[Term] Definition.
\item[Agent] One of the $k$ entities of a MAPF instance, with its own start vertex and goal vertex.
\item[Classical MAPF] The multi-agent path finding problem on an undirected graph with discrete time, synchronous unit-time move and wait actions, distinct starts and goals, stay-at-target, and vertex and swapping conflicts forbidden.
\item[Cycle conflict] A set of agents that all move at the same time step, each into the vertex the next one is leaving, rotating along a fully occupied cycle; allowed in this book.
\item[Disappear-at-target] The convention in which an agent is removed from the graph the moment it first reaches its goal; not used in this book.
\item[Edge conflict] Two agents traversing the same edge in the same direction in the same time step; it implies a vertex conflict at the start of the step.
\item[Following conflict] One agent entering, at time $t+1$, the vertex that another agent occupied at time $t$; allowed in this book because synchronous motion keeps a one-edge gap.
\item[Horizon of a plan] The largest path cost $T=\max_i T_i$ in a plan; no vertex or swapping conflict can first appear after it.
\item[Naive plan] The plan made of independent shortest paths, one per agent, ignoring all other agents; its costs are lower bounds for every valid solution.
\item[Plan (MAPF)] A tuple of one time-indexed path per agent; viewed as a table with agents as rows and time steps as columns.
\item[Scenario file] A \code{.scen} text file of the MAPF benchmark listing start--goal pairs as $x$ (column) and $y$ (row) coordinates on a named \code{.map} grid.
\item[Stay-at-target] The convention in which an agent that has reached its goal remains there forever and keeps blocking the vertex; the cost of its path is the time of its last arrival.
\item[Swapping conflict] Two agents traversing the same edge in opposite directions in the same time step, exchanging vertices; forbidden in this book.
\item[Time-indexed path] A sequence of vertices $\pi_i[0],\dots,\pi_i[T_i]$ from start to goal in which consecutive entries are equal (a wait) or adjacent in the graph (a move).
\item[Valid solution] A plan whose paths are legal and which has no vertex or swapping conflict at any time under stay-at-target.
\item[Vertex conflict] Two agents occupying the same vertex at the same time step; forbidden in this book.
