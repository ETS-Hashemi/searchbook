% Glossary terms from ch06: lines of the form \item[Term] Definition.
\item[Anytime algorithm] A planner that returns a first, possibly poor, solution quickly and then keeps improving it, so that it can be interrupted at any moment and still hand back the best solution found so far together with a quality certificate.
\item[Inflation factor] The weight $\eps\ge1$ that \arastar puts on the heuristic in its key $\fcost_\eps=\gcost+\eps\,\hcost$; a large $\eps$ makes the search greedy and fast, $\eps=1$ makes it plain \astar.
\item[ImprovePath] The inner loop of \arastar: expand the state with the smallest $\fcost_\eps$ until the goal's key is no larger than every key in \Open; each state is expanded at most once per call and the result is an $\eps$-suboptimal path.
\item[Inconsistent state] A state whose $\gcost$-value has been lowered since it was last expanded (or that has never been expanded); the set of inconsistent states is exactly $\Open\cup\textsc{Incons}$, and only they can still improve the search.
\item[INCONS list] The states that were expanded in the current iteration and whose $\gcost$ was lowered afterwards; \arastar records the improvement but does not re-expand them until the next iteration, when they are merged into \Open.
\item[Suboptimality certificate] The bound $\eps'=\min\bigl(\eps,\ \gcost(\gamma)/\min_{n\in\Open\cup\textsc{Incons}}(\gcost(n)+\hcost(n))\bigr)$ published with every \arastar path; the path costs at most $\eps'\,C^*$, and usually $\eps'$ is much smaller than $\eps$.
\item[Epsilon schedule] The sequence $\eps_1>\eps_2>\dots>\eps_K=1$ of inflation factors that \arastar runs through; it fixes the time to the first path, the number of published improvements and the total work.
\item[Restarted weighted A*] The naive anytime search that runs weighted \astar from scratch once per inflation factor; it repeats the work of every previous run, which \arastar avoids by keeping $\gcost$-values, \Open and \textsc{Incons}.
\item[Anytime D*] The combination of \arastar with \dstarlite: an anytime planner whose $\gcost$/$\rhs$ bookkeeping also repairs the search when edge costs change, inflating the keys of overconsistent states only.
\item[Deadline] The time by which the replanning layer must deliver a path; an anytime planner meets it with the best path found so far, a fixed-budget optimal search may miss it altogether.
