\begin{solution}{exr:ch10-focal-by-hand}
(a) $\fcost_{\min}=10$ and the band is $\fcost\le13$, so $\Focal=\set{(10,3),(11,1),(12,0),(13,4)}$ and the node $(12,0)$ is expanded. (b) The successor $(12,2)$ enters the band, $(16,0)$ does not; $\Focal=\set{(10,3),(11,1),(13,4),(12,2)}$ and $(11,1)$ is expanded. (c) $(15,0)$ is in \Focal exactly when $15\le10w$, that is, $w\ge1.5$. It is still not expanded before $(12,0)$: both have $\hcost_{\Focal}=0$ and the tie goes to the smaller $\fcost$. (d) The band is $\fcost\le1.3\cdot13=16.9$, so $\Focal=\set{(13,4),(14,2),(15,0),(16,0)}$; the two nodes with $\hcost_{\Focal}=0$ tie and $(15,0)$, with the smaller $\fcost$, is expanded. Note that $(16,0)$ sat in \Open with $\hcost_{\Focal}=0$ the whole time and was ignored until the band reached it; this is the ruler doing its job.
\end{solution}

\begin{solution}{exr:ch10-w-one}
Low level: with $w=1$ the band is $\set{n\in\Open:\fcost(n)\le\fcost_{\min}}$, that is, the states with $\fcost=\fcost_{\min}$. The goal state $(\gamma_i,t)$ is chosen from the band, so $t=\fcost(\gamma_i,t)=\fcost_{\min}$, and \cref{thm:ch10-lowlevel-lb} gives $\fcost_{\min}\le C_i^*(\mathcal{C}_i)\le t=\fcost_{\min}$: the path is optimal and the returned bound equals its cost. Hence every path in every CT node is optimal for its constraints and $\mathrm{LB}_i(N)=\cost(N.\pi_i)$, so $\mathrm{LB}(N)=\cost(N)$ for every node (the maximum at line~\ref{alg:ch10-ecbs:lb} of \cref{alg:ch10-ecbs} changes nothing, because a child's constrained optimum is at least the parent's). High level: the band is $\set{N\in\Open:\cost(N)\le\mathrm{LB}}$ with $\mathrm{LB}=\min_{N'}\mathrm{LB}(N')=\min_{N'}\cost(N')$; since $\cost(N)\ge\mathrm{LB}$ for every open node, the band consists of the nodes of minimum cost, and the one with the fewest conflicts is expanded. This is exactly \cbs with \Open ordered by cost and ties broken by $h_c$, which returns an optimal solution by the argument of \cref{ch:ch09}, or directly by \cref{thm:ch10-ecbs} with $w=1$. The self-test of \code{ch10\_ecbs.py} checks on random instances that \code{ecbs(inst, w=1.0)} returns the cost of \code{cbs(inst)}.
\end{solution}

\begin{solution}{exr:ch10-lowlevel-threshold}
(a) The waiting state has $\fcost=4$ and $\fcost_{\min}=3$, so it enters the band exactly when $4\le3w$, that is, $w\ge4/3$. For $w<4/3$ the band contains only states with $\fcost=3$ and the conflicting straight path is returned; for $w\ge4/3$ the waiting state is expanded first because its conflict count is~$0$, and the path of cost~4 is returned. (b) In \python, \code{3 * (4/3)} evaluates to \code{4.0}, so the test happens to succeed, but this is an accident of rounding: \code{4/3} is stored slightly below $4/3$ and the product happens to round up. Store $w$ as a fraction $p/q$ and test $q\,\fcost\le p\,\fcost_{\min}$ in integers, or compare against $w\,\fcost_{\min}+10^{-9}$. (c) Now B occupies $(1,1)$ at $t=1$ and $t=2$, so both the straight path and the path with one wait have a conflict, and every conflict-free path costs~5: wait twice at $(1,0)$, or go around through row~0 or row~2. With $w=1.5$ the band is $\fcost\le4.5$ and no conflict-free path fits: the search expands the wait first, finds that $(1,1)$ at $t=2$ conflicts too, and returns the straight path of cost~3 with one conflict and the bound~3 after four expansions. With $w=2$ the band reaches $\fcost\le6$ and the horizon $\lfloor2\cdot4\rfloor=8$; the search returns the path that waits twice, $(1,0),(1,0),(1,0),(1,1),(1,2),(1,3)$, of cost~5 with no conflict, again with the bound~3. \code{focal\_space\_time\_astar} confirms all four runs.
\end{solution}

\begin{solution}{exr:ch10-bcbs-proof}
Fix an optimal solution $\Pi^*$ and call a node consistent if $\Pi^*$ respects all its constraints. The proof of \cref{thm:ch10-consistent} goes through unchanged: the root is consistent, a consistent node has a child that is consistent, and that child's low-level call succeeds. Now let $N$ be consistent. Each path $N.\pi_i$ was produced by a focal low level with factor $w_L$ under a constraint set $\mathcal{C}\subseteq N.\mathcal{C}_i$ (the constraints of $N$ itself or of the ancestor in which $a_i$ was last replanned). By \cref{thm:ch10-focal} applied to that search, $\cost(N.\pi_i)\le w_L\,C_i^*(\mathcal{C})$, and since $\pi_i^*$ respects $\mathcal{C}$, $C_i^*(\mathcal{C})\le\cost(\pi_i^*)$. Summing, $\cost(N)\le w_L\sum_i\cost(\pi_i^*)=w_L\,C^*$. Hence at every moment $\min_{N'\in\Open}\cost(N')\le w_L\,C^*$, and the solution node returned from the band satisfies $\cost\le w_H\min_{N'}\cost(N')\le w_Hw_L\,C^*$. \ecbs saves the factor $w_L$ because it compares the band with $\mathrm{LB}$, which bounds $C^*$ directly ($\mathrm{LB}\le C^*$), instead of with the smallest cost, which only bounds $w_L\,C^*$; the price is that every low-level search must return its $\fcost_{\min}$ and every node must carry the per-agent bounds.
\end{solution}
