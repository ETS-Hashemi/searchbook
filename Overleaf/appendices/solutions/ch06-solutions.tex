\begin{solution}{exr:ch06-trace}
(a) The five cells generated in step~2, with their keys for $\eps = 3$ and, in brackets, for $\eps = 1$: $(2,2)$, $\gcost = 2.41$, $\hcost = 5.00$, key $17.41$ [$7.41$]; $(2,3)$, $2.00$, $5.41$, $18.24$ [$7.41$]; $(2,4)$, $2.41$, $5.83$, $19.90$ [$8.24$]; $(1,2)$, $2.00$, $6.00$, $20.00$ [$8.00$]; $(1,4)$, $2.00$, $6.83$, $22.49$ [$8.83$]. The diagonal step to $(2,2)$ costs $0.41$ more in $\gcost$ than the straight step to $(2,3)$, but it also reduces $\hcost$ by $0.41$ more; with $\eps = 3$ that saving counts three times, $3 \cdot 0.41 = 1.24 > 0.41$, so the diagonal key is $0.83$ smaller and the diagonal neighbors go first. With $\eps = 1$ the two are tied at $7.41$ and only the tie-break decides. (b) Keys $\gcost + 2\hcost$ at the start of iteration~2: $(3,3)$ (from \textsc{Incons}) $3.00 + 8.83 = 11.83$; $\gamma$ $12.24 + 0 = 12.24$; $(1,2)$ $14.00$; $(2,4)$ $14.07$; $(2,1)$ $14.24$; $(3,0)$ $14.49$; $(4,5)$ $15.31$; $(1,4)$ $15.66$; $(1,1)$ $16.66$. The corrected state $(3,3)$ is smallest and the goal second, which is why the postponed re-expansion happens at once and the iteration is over after four expansions. (c) $\gcost(\gamma) = 12.24 = 8 + 3\sqrt{2}$ is the value inherited from iteration~1 along $s, (1,3), (2,2), (3,2), (4,3), (5,4), (5,5), (6,5), (7,5), (7,4), (7,3), \gamma$; nothing in iteration~2 relaxes $\gamma$, so it stays. The pointer path is read backward from $\gamma$ and now enters $(4,3)$ through the corrected $(3,3)$: $s, (1,3), (2,3), (3,3), (4,3), (5,4), (5,5), (6,5), (7,5), (7,4), (7,3), \gamma$, ten straight moves and one diagonal, $10 + \sqrt{2} = 11.41$. The two differ by exactly the correction $4.83 - 4.00 = 0.83$ that $(3,3)$ passed to $(4,3)$. To push $\gcost(\gamma)$ down to $11.41$ inside iteration~2 the search would have to re-expand the whole tail $(5,5)$, $(6,5)$, $(7,5)$, $(7,4)$, $(7,3)$ and relax $\gamma$ once more --- five expansions whose keys, starting at $6.41 + 2 \cdot 3.83 = 14.07$, all exceed the goal's key $12.24$, so the termination test fires first. \arastar publishes the pointer path instead and gets the same cost for nothing.
\end{solution}

\begin{solution}{exr:ch06-bound}
(a) With the octile distance to $\gamma = (7,2)$: $(1,1)$: $3.83 + 6.41 = 10.24$; $(1,2)$: $2.00 + 6.00 = 8.00$; $(1,4)$: $2.00 + 6.83 = 8.83$; $(2,1)$: $3.41 + 5.41 = 8.83$; $(2,4)$: $2.41 + 5.83 = 8.24$; $(3,0)$: $4.83 + 4.83 = 9.66$; $(4,5)$: $6.83 + 4.24 = 11.07$; $(7,2)$: $12.24 + 0 = 12.24$; and $(3,3)$ in \textsc{Incons}: $3.00 + 4.41 = 7.41$. So $L = 7.41$ and $\eps' = \min(3,\ 12.24/7.41) = 1.65$. (b) Over \Open alone the minimum is $8.00$ from $(1,2)$, giving $\eps' = 1.53$. On this instance the number happens to be a valid bound, since the true ratio is $1.20$, but nothing guarantees it: \cref{exr:ch06-incons} shows a graph on which the same mistake certifies a suboptimal path as optimal. (c) Let $n$ have a finite $\gcost$ and let $P$ be its pointer path from $s$, of cost at most $\gcost(n)$ by \cref{thm:ch06-pointer}. Applying $\hcost(u) \le c(u,u') + \hcost(u')$ along the edges of $P$ gives $\hcost(s) \le \cost(P) + \hcost(n) \le \gcost(n) + \hcost(n)$. Hence $\hcost(s) \le L$, and because $\hcost(s) \le C^*$ by admissibility, $\gcost(\gamma) \le (\gcost(\gamma)/\hcost(s))\,C^*$ is a valid certificate; but $\gcost(\gamma)/L \le \gcost(\gamma)/\hcost(s)$, so the certificate of \cref{eq:ch06-certificate} is never worse. In iteration~1 the two coincide, $\hcost(s) = 7.41 = L$, because the straight route $s \to (1,3) \to (2,3) \to (3,3)$ followed by the octile estimate from $(3,3)$ costs exactly the octile estimate from $s$: no detour has yet been forced on the cheapest inconsistent state. As soon as an inconsistent state lies behind a wall, $L$ exceeds $\hcost(s)$ and the list-based certificate wins.
\end{solution}

\begin{solution}{exr:ch06-proof}
(a) Sketch. Show that each operation preserves the three claims: generation of a new state (pushes it into \Open, $v = \infty > \gcost$), relaxation of a non-closed state (stays in or enters \Open, still inconsistent), relaxation of a closed state (enters \textsc{Incons}; it is closed, so it was expanded in this iteration), expansion (removes the state from \Open, sets $v = \gcost$, so it becomes consistent and is in neither list), and the merge on line~\ref{alg:ch06-main:merge} (moves states between the lists without changing $v$ or $\gcost$). If \Closed were not emptied, a state expanded in an earlier iteration and improved in this one would be sent to \textsc{Incons} although it was not expanded in this iteration: the last sentence of (iii) fails, and with it Case~3 of the proof of \cref{thm:ch06-bound}, which needs that a state in \textsc{Incons} was selected in the \emph{current} call, where the induction hypothesis applies. Its improvement would also not be propagated until the next iteration, for no reason. (b) Let $u \in \textsc{Incons}$ be the first inconsistent state on the optimal path $P$. All states before $u$ on $P$ are consistent, so \cref{thm:ch06-invariants}(ii) with $v = \gcost$ telescopes to $\gcost(u) \le \gcost^*(u)$, and (i) gives equality. Membership of $u$ in $\Open \cup \textsc{Incons}$ is (iii); that $u$ is in \textsc{Incons} rather than \Open changes nothing, because \cref{eq:ch06-lower} ranges over both lists. Admissibility of $\hcost$ then gives $L \le \gcost(u) + \hcost(u) \le \gcost^*(u) + \hcost^*(u) = C^*$. (c) With $\eps = 1$: expand $s$ (key $0$), which gives $a$ the key $1 + 3 = 4$ and $b$ the key $3 + 0 = 3$; expand $b$, which gives $\gamma$ the key $5$; expand $a$ (key $4 < 5$), which lowers $\gcost(b)$ from $3$ to $2$, but $b$ is closed and goes to \textsc{Incons}. Now \Open holds only $\gamma$ with key $5$, the loop stops, and $\gcost(\gamma) = 5 > C^* = 4$. The lists give $L = \min(5,\ 2 + 0) = 2$ and $\eps' = \min(1, 5/2) = 1$: a false certificate (the pointer path $s \to a \to b \to \gamma$ happens to cost $4$, but the value $\gcost(\gamma)$ that the certificate is about is $5$). In the proof, take $n = \gamma$ at the exit and the optimal path $s, a, b, \gamma$: the first violating state is $\gamma$ itself, $m = b$ is in \textsc{Incons}, and Case~3 says that $b$ violated the claim when it was selected with $v(b) = 3 > \gcost^*(b) = 2$. At that moment $a$ was in \Open, and Case~2 for that selection needs $\hcost(a) \le c(a,b) + \hcost(b) = 1$; the actual value $\hcost(a) = 3$ breaks the inequality, $\fcost_1(a) = 4 > 3 = \fcost_1(b)$, and no contradiction arises. Consistency is used exactly there.
\end{solution}

\begin{solution}{exr:ch06-incons}
(a) Every edge satisfies $\hcost(u) \le c(u,u') + \hcost(u')$: for instance $\hcost(s) = 2 \le 1 + \hcost(b) = 2$, $\hcost(a) = 2 \le 1 + \hcost(c) = 2$ and $\hcost(e) = 2 \le 2 + 0$. The optimal path is $s \to a \to c \to e \to \gamma$ with $C^* = 5$; the decoy $s \to d \to \gamma$ costs $5.5$ and $s \to b \to c \to \gamma$ costs $8$. (b) Iteration~1, $\eps = 3$: expand $s$ (key $6$), generating $a$ ($\gcost = 1$, key $7$), $b$ ($1$, key $4$) and $d$ ($2$, key $8$); expand $b$, generating $c$ ($3$, key $6$); expand $c$, generating $\gamma$ ($8$, key $8$) and $e$ ($4$, key $10$); expand $a$ (key $7$), which lowers $\gcost(c)$ to $2$ --- $c$ is closed and goes to \textsc{Incons}. The goal's key $8$ is now at most the smallest key in \Open ($d$ with $8$), so the iteration stops after four expansions with $\textsc{Incons} = \{c\}$. The pointer path is $\gamma \to c \to a \to s$, cost $7$, while $\gcost(\gamma) = 8$; $L = \min(c{:}\,2+1,\ d{:}\,2+2,\ e{:}\,4+2,\ \gamma{:}\,8) = 3$ and $\eps' = \min(3, 8/3) = 2.67$. Iteration~2, $\eps = 1$: \Open holds $c$ (key $3$), $d$ ($4$), $e$ ($6$), $\gamma$ ($8$). Expand $c$: $\gamma$ drops to $7$, $e$ to $3$ (key $5$); expand $d$: $\gamma$ drops to $5.5$ with parent $d$; expand $e$ (key $5 < 5.5$): $\gamma$ drops to $5$ with parent $e$. The loop stops, the published path is $s \to a \to c \to e \to \gamma$ with cost $5$, $L = 5$ and $\eps' = 1$. (c) Without \textsc{Incons} the second iteration starts from \Open $= \{d, e, \gamma\}$ with keys $4, 6, 8$: expand $d$, which lowers $\gamma$ to $5.5$, and the loop stops at once because $5.5 \le 6$. The published path is $s \to d \to \gamma$ with cost $5.5 > C^*$, and the lists give $L = \min(e{:}\,4+2,\ \gamma{:}\,5.5) = 5.5$, hence $\eps' = 1$: a suboptimal path certified as optimal. The cause is that $e$ still carries the stale value $\gcost(e) = 4$ computed from $v(c) = 3$; the correction $\gcost(c) = 2$ was never propagated. (d) Re-opening $c$ in iteration~1 would expand it again with $\gcost = 2$, lower $\gamma$ to $7$ and $e$ to $3$ at once, and the bound of weighted \astar with re-opening (\cref{ch:ch04}) still holds. The cost is that a state may be expanded many times in one iteration on inflated keys, so the ``at most $\abs{V}$ expansions per iteration'' guarantee of \cref{thm:ch06-properties}(i) is lost, and with it the predictability of the time to the next published path.
\end{solution}

\begin{solution}{exr:ch06-schedule}
(a) Decrease of the mean cost ratio per $100$ expansions, iteration by iteration. \arastar: iterations~2 and~3 improve nothing at no cost; iteration~4 gains $0.0003$ for a single expansion; then $0.0152$ (iteration~5, $83$ expansions), $0.0136$ ($435$), $0.0021$ ($480$) and $0.0001$ ($328$). Restarts: $0.0056$ ($224$ expansions), $0.0075$ ($244$), $0.0069$ ($298$), $0.0028$ ($346$), $0.0022$ ($590$), $0.0009$ ($875$), $0.00003$ ($1\,173$). Improvement is cheapest in the middle for both, iterations~5 and~6 for \arastar and~3 and~4 for the restarts, and it becomes very expensive at the end, where the work buys the guarantee rather than a shorter path. (b) \arastar's cumulative expansions are $215, 215, 215, 216, 298, 733, 1213, 1541$: after $800$ expansions iteration~6 ($\eps = 1.25$) is the last complete one, so the published path costs $1.0105\,C^*$ with the certificate $1.226$, and iteration~7 is running. The restarts stand at $683$ after the run with $\eps = 2$ and are in the middle of the one with $\eps = 1.75$, so they offer $1.0518\,C^*$ with the guarantee $2$. Plain \astar needs $1\,177$ expansions and has nothing at all. (c) By \cref{thm:ch06-properties}(iv) an iteration expands nothing when the incumbent already satisfies the termination test for the new $\eps$, which is the case here: $\gcost(\gamma) \le \eps \cdot L$ holds for $\eps = 2.5$ and $2$ because it holds with the ratio $1.412$. Neither $\gcost(\gamma)$ nor $L$ changes, so $\eps' = \min(\eps, \gcost(\gamma)/L)$ keeps the value $1.412$: it cannot rise to $2.5$ or $2$, since the minimum takes the ratio, and it cannot fall, since nothing was improved. (d) From $\eps_1 = 3$ the first certificate is $\eps'_1 = 1.65$, so $\eps_2 = \max(1, 1.65 - 0.2) = 1.45$; that iteration costs 13 expansions, finds the optimal path (cost $10.24$) and certifies it with $\eps'_2 = 1.16$; then $\eps_3 = \max(1, 1.16 - 0.2) = 1$, and two expansions raise $L$ to $10.24$ and give $\eps' = 1$. The schedule is $3 \to 1.45 \to 1$ with $17 + 13 + 2 = 32$ expansions, the same total as $3, 2, 1$, but the optimal path is already on the table after $30$ of them, and one intermediate publication is saved.
\end{solution}

\begin{solution}{exr:ch06-coding}
Expected outcome. (a) The three iterations must give $17$, $4$ and $11$ expansions with published costs $12.24$, $11.41$ and $10.24$ and certificates $1.65$, $1.53$ and $1.00$; a different count in iteration~1 usually means a different tie-breaking rule (the reference breaks ties on the key toward the smaller $\hcost$, then first in first out), a different count in iteration~2 means that \textsc{Incons} or the re-keying is wrong, and a cost of $12.24$ instead of $11.41$ in iteration~2 means that the path is read from stale $\gcost$-values instead of from the parent pointers. (b) The checks are those of the self-test of \code{ch06\_arastar.py}; the one that fails most often in fresh implementations is $L \le C^*$, because $L$ was computed over \Open only. (c) Against expansions the curves look like \cref{fig:ch06-anytime}: identical first points for every method, flat stretches where \arastar expands nothing, and a total between $1.2$ and $1.5$ times the expansions of \astar for \arastar. Against wall-clock time the picture is the same up to a constant, except that the re-keying between iterations becomes visible as small steps for long schedules; the first-solution time of \arastar is that of weighted \astar with $\eps_1$, and plain \astar has no point at all before its single one. (d) With a budget the generator must be interrupted inside \code{improve\_path()}, for instance by checking the clock every $200$ expansions and raising a flag that makes the while loop exit; the pointer path at that moment is valid (\cref{thm:ch06-pointer}) and no worse than $\gcost(\gamma)$, which has not increased since the last publication, so the last certificate still applies. Keep the best path published so far and return that if the interrupted iteration has not improved on it; the self-test reports no instance with a non-monotone published cost sequence, but the guard costs nothing.
\end{solution}

\begin{solution}{exr:ch06-deadline}
(a) $20\,000 \cdot 0.05 = 1\,000$ expansions per cycle. On the maps of \cref{tab:ch06-experiment} \arastar has then completed iteration~6 ($\eps = 1.25$, $733$ expansions cumulative) and is inside iteration~7, so it delivers a path of $1.0105\,C^*$ with the certificate $1.226$; the restarts have completed the run with $\eps = 1.75$ ($980$) and deliver $1.0312\,C^*$ with the guarantee $1.75$; plain \astar needs $1\,177$ expansions and delivers nothing. With a $20$~ms cycle, $400$ expansions: \arastar has finished iteration~5 and offers $1.0698\,C^*$ with the certificate $1.378$, the restarts have only the $\eps = 3$ run ($215$) and offer $1.0827\,C^*$, and \astar again has nothing. (b) At any moment inside an iteration the parent pointers from $\gamma$ form a valid simple path of cost at most the current $\gcost(\gamma)$ (\cref{thm:ch06-pointer}), and $\gcost(\gamma)$ never increases, so it is at most the value published at the end of the previous iteration. That value was certified by $\eps'$, hence the interrupted path also costs at most $\eps' C^*$. What the interrupt does not give is a \emph{better} certificate: $L$ computed in mid-iteration is still a valid lower bound by \cref{thm:ch06-bound}, but the new $\gcost(\gamma)$ has not yet passed the termination test, so the honest answer is the old pair. (c) The iteration-2 path runs $s, (1,3), (2,3), (3,3), (4,3), (5,4), (5,5), (6,5), (7,5), (7,4), (7,3), \gamma$, so blocking $(4,3)$ invalidates the pointer chain of every cell behind it: $(5,3)$, $(5,4)$, $(5,5)$, $(6,5)$, $(7,5)$, $(7,4)$, $(7,3)$ and $\gamma$ keep $\gcost$-values that no longer correspond to any path. In the vocabulary of \cref{ch:ch05} they are underconsistent, $\gcost < \rhs$; \arastar has no machinery for that case, because raising a $\gcost$-value never happens in a search from a fixed start, so all it can do is start again from scratch (the $\gcost$-values of the cells not behind $(4,3)$ may be kept as an initialization, but the guarantee then has to be re-earned). Anytime \dstar is the algorithm that handles it: it searches backward from the goal, so the drone's own motion only changes the key modifier, and it propagates the raised values first with uninflated keys before inflating again; if the increase is large it also raises $\eps$, trading the guarantee for the speed needed to repair. (d) A workable rule: if the certificate is below the mission tolerance and the map has not changed, keep improving; if a change invalidates cells on the current path but the remaining budget is at least the cost of one iteration at the current $\eps$, raise $\eps$ to the last certificate plus a margin and repair; restart only when the change is near the start or the pointer path is no longer valid at all. The quantities to read are the certificate $\eps'$, the expansions of the last iteration as an estimate of the next one, and the number of invalidated cells on the path.
\end{solution}
