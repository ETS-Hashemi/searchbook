\begin{solution}{exr:ch06-bound}
(a) With the octile distance to $\gamma = (7,2)$: $(1,1)$: $3.83 + 6.41 = 10.24$; $(1,2)$: $2.00 + 6.00 = 8.00$; $(1,4)$: $2.00 + 6.83 = 8.83$; $(2,1)$: $3.41 + 5.41 = 8.83$; $(2,4)$: $2.41 + 5.83 = 8.24$; $(3,0)$: $4.83 + 4.83 = 9.66$; $(4,5)$: $6.83 + 4.24 = 11.07$; $(7,2)$: $12.24 + 0 = 12.24$; and $(3,3)$ in \textsc{Incons}: $3.00 + 4.41 = 7.41$. So $L = 7.41$ and $\eps' = \min(3,\ 12.24/7.41) = 1.65$. (b) Over \Open alone the minimum is $8.00$ from $(1,2)$, giving $\eps' = 1.53$. On this instance the number happens to be a valid bound, since the true ratio is $1.20$, but nothing guarantees it: \cref{exr:ch06-incons} shows a graph on which the same mistake certifies a suboptimal path as optimal. (c) Let $n$ have a finite $\gcost$ and let $P$ be its pointer path from $s$, of cost at most $\gcost(n)$ by \cref{thm:ch06-pointer}. Applying $\hcost(u) \le c(u,u') + \hcost(u')$ along the edges of $P$ gives $\hcost(s) \le \cost(P) + \hcost(n) \le \gcost(n) + \hcost(n)$. Hence $\hcost(s) \le L$, and because $\hcost(s) \le C^*$ by admissibility, $\gcost(\gamma) \le (\gcost(\gamma)/\hcost(s))\,C^*$ is a valid certificate; but $\gcost(\gamma)/L \le \gcost(\gamma)/\hcost(s)$, so the certificate of \cref{eq:ch06-certificate} is never worse. In iteration~1 the two coincide, $\hcost(s) = 7.41 = L$, because the straight route $s \to (1,3) \to (2,3) \to (3,3)$ followed by the octile estimate from $(3,3)$ costs exactly the octile estimate from $s$: no detour has yet been forced on the cheapest inconsistent state. As soon as an inconsistent state lies behind a wall, $L$ exceeds $\hcost(s)$ and the list-based certificate wins.
\end{solution}

\begin{solution}{exr:ch06-proof}
(a) Sketch. Show that each operation preserves the three claims: generation of a new state (pushes it into \Open, $v = \infty > \gcost$), relaxation of a non-closed state (stays in or enters \Open, still inconsistent), relaxation of a closed state (enters \textsc{Incons}; it is closed, so it was expanded in this iteration), expansion (removes the state from \Open, sets $v = \gcost$, so it becomes consistent and is in neither list), and the merge on line~\ref{alg:ch06-main:merge} (moves states between the lists without changing $v$ or $\gcost$). If \Closed were not emptied, a state expanded in an earlier iteration and improved in this one would be sent to \textsc{Incons} although it was not expanded in this iteration: the last sentence of (iii) fails, and with it Case~3 of the proof of \cref{thm:ch06-bound}, which needs that a state in \textsc{Incons} was selected in the \emph{current} call, where the induction hypothesis applies. Its improvement would also not be propagated until the next iteration, for no reason. (b) Let $u \in \textsc{Incons}$ be the first inconsistent state on the optimal path $P$. All states before $u$ on $P$ are consistent, so \cref{thm:ch06-invariants}(ii) with $v = \gcost$ telescopes to $\gcost(u) \le \gcost^*(u)$, and (i) gives equality. Membership of $u$ in $\Open \cup \textsc{Incons}$ is (iii); that $u$ is in \textsc{Incons} rather than \Open changes nothing, because \cref{eq:ch06-lower} ranges over both lists. Admissibility of $\hcost$ then gives $L \le \gcost(u) + \hcost(u) \le \gcost^*(u) + \hcost^*(u) = C^*$. (c) With $\eps = 1$: expand $s$ (key $0$), which gives $a$ the key $1 + 3 = 4$ and $b$ the key $3 + 0 = 3$; expand $b$, which gives $\gamma$ the key $5$; expand $a$ (key $4 < 5$), which lowers $\gcost(b)$ from $3$ to $2$, but $b$ is closed and goes to \textsc{Incons}. Now \Open holds only $\gamma$ with key $5$, the loop stops, and $\gcost(\gamma) = 5 > C^* = 4$. The lists give $L = \min(5,\ 2 + 0) = 2$ and $\eps' = \min(1, 5/2) = 1$: a false certificate (the pointer path $s \to a \to b \to \gamma$ happens to cost $4$, but the value $\gcost(\gamma)$ that the certificate is about is $5$). In the proof, take $n = \gamma$ at the exit and the optimal path $s, a, b, \gamma$: the first violating state is $\gamma$ itself, $m = b$ is in \textsc{Incons}, and Case~3 says that $b$ violated the claim when it was selected with $v(b) = 3 > \gcost^*(b) = 2$. At that moment $a$ was in \Open, and Case~2 for that selection needs $\hcost(a) \le c(a,b) + \hcost(b) = 1$; the actual value $\hcost(a) = 3$ breaks the inequality, $\fcost_1(a) = 4 > 3 = \fcost_1(b)$, and no contradiction arises. Consistency is used exactly there.
\end{solution}

\begin{solution}{exr:ch06-incons}
(a) Every edge satisfies $\hcost(u) \le c(u,u') + \hcost(u')$: for instance $\hcost(s) = 2 \le 1 + \hcost(b) = 2$, $\hcost(a) = 2 \le 1 + \hcost(c) = 2$ and $\hcost(e) = 2 \le 2 + 0$. The optimal path is $s \to a \to c \to e \to \gamma$ with $C^* = 5$; the decoy $s \to d \to \gamma$ costs $5.5$ and $s \to b \to c \to \gamma$ costs $8$. (b) Iteration~1, $\eps = 3$: expand $s$ (key $6$), generating $a$ ($\gcost = 1$, key $7$), $b$ ($1$, key $4$) and $d$ ($2$, key $8$); expand $b$, generating $c$ ($3$, key $6$); expand $c$, generating $\gamma$ ($8$, key $8$) and $e$ ($4$, key $10$); expand $a$ (key $7$), which lowers $\gcost(c)$ to $2$ --- $c$ is closed and goes to \textsc{Incons}. The goal's key $8$ is now at most the smallest key in \Open ($d$ with $8$), so the iteration stops after four expansions with $\textsc{Incons} = \{c\}$. The pointer path is $\gamma \to c \to a \to s$, cost $7$, while $\gcost(\gamma) = 8$; $L = \min(c{:}\,2+1,\ d{:}\,2+2,\ e{:}\,4+2,\ \gamma{:}\,8) = 3$ and $\eps' = \min(3, 8/3) = 2.67$. Iteration~2, $\eps = 1$: \Open holds $c$ (key $3$), $d$ ($4$), $e$ ($6$), $\gamma$ ($8$). Expand $c$: $\gamma$ drops to $7$, $e$ to $3$ (key $5$); expand $d$: $\gamma$ drops to $5.5$ with parent $d$; expand $e$ (key $5 < 5.5$): $\gamma$ drops to $5$ with parent $e$. The loop stops, the published path is $s \to a \to c \to e \to \gamma$ with cost $5$, $L = 5$ and $\eps' = 1$. (c) Without \textsc{Incons} the second iteration starts from \Open $= \{d, e, \gamma\}$ with keys $4, 6, 8$: expand $d$, which lowers $\gamma$ to $5.5$, and the loop stops at once because $5.5 \le 6$. The published path is $s \to d \to \gamma$ with cost $5.5 > C^*$, and the lists give $L = \min(e{:}\,4+2,\ \gamma{:}\,5.5) = 5.5$, hence $\eps' = 1$: a suboptimal path certified as optimal. The cause is that $e$ still carries the stale value $\gcost(e) = 4$ computed from $v(c) = 3$; the correction $\gcost(c) = 2$ was never propagated. (d) Re-opening $c$ in iteration~1 would expand it again with $\gcost = 2$, lower $\gamma$ to $7$ and $e$ to $3$ at once, and the bound of weighted \astar with re-opening (\cref{ch:ch04}) still holds. The cost is that a state may be expanded many times in one iteration on inflated keys, so the ``at most $\abs{V}$ expansions per iteration'' guarantee of \cref{thm:ch06-properties}(i) is lost, and with it the predictability of the time to the next published path.
\end{solution}

\begin{solution}{exr:ch06-coding}
Expected outcome. (a) The three iterations must give $17$, $4$ and $11$ expansions with published costs $12.24$, $11.41$ and $10.24$ and certificates $1.65$, $1.53$ and $1.00$; a different count in iteration~1 usually means a different tie-breaking rule (the reference breaks ties on the key towards the smaller $\hcost$, then first in first out), a different count in iteration~2 means that \textsc{Incons} or the re-keying is wrong, and a cost of $12.24$ instead of $11.41$ in iteration~2 means that the path is read from stale $\gcost$-values instead of from the parent pointers. (b) The checks are those of the self-test of \code{ch06\_arastar.py}; the one that fails most often in fresh implementations is $L \le C^*$, because $L$ was computed over \Open only. (c) Against expansions the curves look like \cref{fig:ch06-anytime}: identical first points for every method, flat stretches where \arastar expands nothing, and a total between $1.2$ and $1.5$ times the expansions of \astar for \arastar. Against wall-clock time the picture is the same up to a constant, except that the re-keying between iterations becomes visible as small steps for long schedules; the first-solution time of \arastar is that of weighted \astar with $\eps_1$, and plain \astar has no point at all before its single one. (d) With a budget the generator must be interrupted inside \code{improve\_path()}, for instance by checking the clock every $200$ expansions and raising a flag that makes the while loop exit; the pointer path at that moment is valid (\cref{thm:ch06-pointer}) and no worse than $\gcost(\gamma)$, which has not increased since the last publication, so the last certificate still applies. Keep the best path published so far and return that if the interrupted iteration has not improved on it; the self-test reports no instance with a non-monotone published cost sequence, but the guard costs nothing.
\end{solution}
