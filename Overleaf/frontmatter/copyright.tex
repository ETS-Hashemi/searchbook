\textbf{Multi-Agent Path Planning and Drone Collision Avoidance}\\
\emph{A Textbook of Algorithms: From Graph Search to Hybrid Swarm Systems}

\medskip\noindent
Typeset with \LaTeX{} (pdf\TeX), TikZ and pgfplots. Figures were drawn in TikZ or generated
from the \python{} reference implementations that accompany the book.

\medskip\noindent
This book was written to accompany a twelve-week research training plan on
multi-agent path planning and collision avoidance for drone swarms. It is intended
for self-study. All algorithms described here are established published methods;
the original sources are cited in each chapter and collected in the bibliography.

\medskip\noindent
Source code, figures and \LaTeX{} sources are distributed together with this book so
that every example can be reproduced and every figure regenerated.
